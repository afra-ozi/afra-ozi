Projects

Standard-library Python 3.9+ with unit tests, sample data and a README. Clone, copy the command, run.

llm-eval-scorer

Weighted rubric scoring for chatbot responses (accuracy, helpfulness, safety, instruction following), rater-disagreement flags and side-by-side win rates.

PythonLLM eval5 tests
python llm_eval.py sample_ratings.csv sample_preferences.csv

annotation-agreement

Cohen's and Fleiss' kappa, percent agreement and a list of items to adjudicate, from any label export.

PythonInter-annotator5 tests
python iaa.py sample_annotations.csv

search-relevance-metrics

NDCG@k, Precision@k and MRR from human relevance ratings, plus the results raters disagree on.

qa-audit-sampler

A fair, reproducible QA audit sample, stratified by annotator and label so nobody and no label is skipped.

Python CLIQA5 tests

data-quality-checker

Rule-based CSV validation configured in JSON: required fields, duplicates, regex formats, allowed values and ranges.

PythonJSON rules4 tests
python dq_check.py sample_records.csv rules.json

sql-data-validation

SQL checks for missing labels, orphan rows, impossible timestamps and speed outliers, with a PASS/FAIL runner on SQLite.

SQLSQLite2 tests

Tasks per hour, handling time and QA pass rate side by side, with flags for who needs a check-in.

Try the rubric

This is the same weighted rubric my llm-eval-scorer uses. Rate the answer below and watch how the weights decide the score.

PromptWhat is the capital of Australia?
Model responseThe capital of Australia is Sydney, the country's largest and best-known city. It is home to the Opera House and a major harbour.

Read it as a rater: it is well written and on-topic, but is it right?

Accuracy carries the most weight, so a fluent but wrong answer can't score well. That's the point of a rubric.
